description: A project's cost report: every cost code's budget, committed, pending variations, spent, forecast final, over budget and cost to complete.
---

1. Run `npm run pd -- costs <project>`.
2. Lead with any code over budget and why (the contracts and variations on it: `npm run pd -- contracts --project=<code>`). Say what is left in contingency.
3. A budget change: `npm run pd -- budget <project> <code> <amount>`, only on the operator's say so.
