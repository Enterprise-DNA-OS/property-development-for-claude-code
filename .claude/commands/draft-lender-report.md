---
description: Draft the monthly report to the lender: cost to complete, presales against the covenant, drawdowns, programme and conditions.
---

1. Run `npm run docs -- lender-report` for the branded report, and read `npm run pd -- project <code> --json`.
2. Write `drafts/lender-report-<project>.md`: a one-paragraph summary (programme, cost, sales), what changed since last month (read the notes), and the risks the lender will ask about (sunset dates before completion, pending variations, presale gap).
3. Do not hide a problem the records show. Never send it.
