---
description: Every contract: value, approved and pending variations, revised value, claimed to date and retention held. Add a contract.
---

1. Run `npm run pd -- contracts` (one project: `--project=PARK`).
2. Call out pending variations and any contract claimed close to its revised value.
3. A new contract: `npm run pd -- contract-new <project> <NUMBER> "Supplier" --value=7450000 --code=500 --kind=construction --retention=5`.
