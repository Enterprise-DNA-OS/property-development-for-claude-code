---
description: Draft the drawdown request letter to the lender: the period, the items by cost code, the total, the cost to complete and the presale position.
---

1. Run `npm run pd -- drawdown <project> --json`, `npm run pd -- costs <project> --json` and `npm run pd -- presales --json`.
2. Write `drafts/drawdown-<project>-<number>.md`: the facility, the period, the items by cost code, the total requested, cost to complete against the undrawn facility, and qualifying presales against the covenant.
3. Leave a line for the QS certificate. Never send it.
